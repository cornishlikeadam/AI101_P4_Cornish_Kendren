# Waldo's Savannah

A search-and-find game in an illustrated Savannah, Georgia. Find the one person with all five clues.

- Play: https://waldo-savannah.vercel.app
- Offline: open `vibe-coding/build/index.html`
- Slides: [Waldo's Savannah, Weeks 7–10 (.pptx)](vibe-coding/docs/presentation/Waldos_Savannah_Weeks_7-10.pptx)

The class project lives in [`vibe-coding/`](vibe-coding/). Start with [vibe-coding/START-HERE.md](vibe-coding/START-HERE.md).

| Folder | What's in it |
|---|---|
| `vibe-coding/` | The game, its source and every class document |
| `lab/` | A separate design workspace I used while redesigning the art. It isn't part of the game. |
| `HARNESS.md`, `HANDOFF.md`, `AGENTS.md` | The rules I gave the AI agents |

All the art is original. The game has no tracking, no accounts and makes no outside requests.
