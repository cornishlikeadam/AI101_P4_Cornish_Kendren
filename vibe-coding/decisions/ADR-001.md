# ADR-001: Single-file geometric Savannah

Status: Replaced by [ADR-002](ADR-002-illustrated-world.md) (full v1 record in `docs/history/ADR-001-v1-full.md`).
Context: The project needed a Savannah search-and-find game that opens from `build/index.html` and runs offline with no outside requests.
Decision: Draw the first version inside one HTML file using angled 3D-style Canvas boxes and no image files.
Consequence: Easy to open offline with zero setup, but characters and landmarks looked like plain geometry blocks instead of a picture book.
