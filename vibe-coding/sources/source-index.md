# Source index

## AI-generated assets

- **All game artwork (`assets/`, ~200 SVG files):** Original buildings, characters, trees, and props generated by Claude Code directly or via scripts in `tools/author/`, and listed in `sources/asset-register.md`. Disclosed in `disclosure.md`.

## Inspiration and reference

- **Waldo Stripes Soft (`waldo-stripes-soft.vercel.app`):** Public web game viewed for search-and-find controls and pacing; no code or art copied.
- **Tiny London / Tiny Savannah (`tiny.london`):** Public site that inspired the dropped v1 isometric camera; viewed only.
- **Savannah landmarks and street layout:** Public knowledge of Bull Street, Forsyth Park, City Market, and River Street (notes in `docs/savannah-blueprint.md`).
- **`playwright-core` (Apache-2.0):** Used only for automated browser tests and screenshots; not shipped inside `build/`.
- **Earlier v1 tools (`REA`, `unslop`, `pixel-worlds`):** Listed in `docs/history/source-index-v1.md`.

## Permitted material

No classmates' files, unlicensed images or fonts, personal data, passwords, or API keys are in this folder. The game uses system fonts and makes zero network requests outside `build/`.
